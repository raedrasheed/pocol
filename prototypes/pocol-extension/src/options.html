PoCol — Studio, IDE & network settings

PoCol wallet

One account for PoCol Mainnet: the same encrypted wallet that PoCol Studio and PoCol IDE sign with. Its key is stored only in this browser, encrypted with your password (PBKDF2-SHA256, 600,000 iterations, AES-256-GCM), and is used only inside the extension. Open the toolbar button for the balance, the network status and Send.

…

Before the wallet reads the network: to show your balance and send what you approve, the extension sends your wallet address, the transactions you approve and the files you choose to publish to the network profile's endpoint (for PoCol Mainnet, the gateway at explorer.pocol.net), which sees your IP address. Everything sent to the blockchain is public and permanent. Your password and private key never leave the extension.

Back up (export)

Saves the encrypted wallet file. Keep it: Chrome deletes the extension's storage when the extension is removed, and the Chrome Web Store item is a separate installation, so this file (and its password) is how you move the wallet. The file is useless without the password, and the password cannot be recovered.

Create or import

Creating or importing replaces the wallet saved in this browser only after you confirm it (back that one up first). A new wallet starts empty.

Only the key of the first account is kept, encrypted; the phrase itself is not stored and the extension cannot show it again. Keep your phrase where it is.

Connected sites

PoCol Studio (studio.pocol.net) and PoCol IDE (ide.pocol.net) never get your key or address on their own: each publication or contract call opens the extension's own confirmation. Websites opened in the PoCol viewer get an account only after you approve it in the viewer, for that tab only; you can end that access here.

      Archived operations of other networks

        Read-only. These were created for another network (another chain ID or genesis) and can no longer be resumed here; they never block this wallet.

        Network profiles

        Paste the profile.json generated by devnet.py init (containing genesisPre, genesisHash, chainId, endpoint and trustLevel).

        A profile of a fresh network omits forkSchedule, which means [[1,"0"]]. After a cap raise that your network operator publishes, use "forkSchedule":[[1,"0"],[2,"H2"],[3,"H3"]] with the operator's exact heights as quoted decimal strings (version 2 changes no rule and only keeps the versions in order; version 3 is the cap raise). The endpoint cannot change the schedule for you. The built-in PoCol Mainnet profile's schedule is fixed by this extension release.

          Local development wallet (local networks only)

          For websites opened from your own local test networks only; it never holds an address on PoCol Mainnet and cannot be exported. Use the PoCol wallet above for Mainnet. The seed is password-encrypted (PBKDF2 600000 + AES-GCM), keys are derived per network, and the wallet locks after 15 minutes.
